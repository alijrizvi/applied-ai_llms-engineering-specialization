# Building AI Systems: **AI Workflow Automation Assistant for Data Engineering Pipelines**

Simulating the role of a Data Engineer, this project utilizes the creation of an AI System, using the ChatGPT API, to suggest optimal data pipeline solutions and automate data engineering workflows.

The system supports various data engineering and data architecture modes:
* ETL
* ELT
* Medallion
* Pipeline Monitoring

### **Course Credits:** DeepLearning.AI's Course "Building Systems with the ChatGPT API"

## **Skills:**

* Multi-Step AI Systems
* System Prompt + Sample Business Request
