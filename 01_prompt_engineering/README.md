# Modern Prompt Engineering for AI Models: **Business Metrics Analyzer**

This project involves the creation of an AI agent, the **Business Metrics Analyzer**, that uses the OpenAI API to convert raw business metrics into actionable insights and suggestions, intending to augment and speed up the work of real-life professionals.

The AI model boasts three modes of work:
* Executive Summary Mode
* Analyst Mode
* Action Recommendation Mode

The user is free to choose which to approach work with.
