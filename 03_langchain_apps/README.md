# **AI Knowledge & Retrieval Assistant**

---
LangChain: An open-source development framework for building LLM applications. Its packages - Python and JavaScript (TypeScript) - are focused on **modularity** and **composition**.
---

In this work, we built a LangChain-powered assistant that chunks, embeds, and retrieves the user's specific data to provide accurate, context-aware answers.

This LLM will extract a piece of text from PDF files, an internal database, or any other directed file path to answer questions about said document.

### **Course Credits:** DeepLearning.AI's Course "LangChain for LLM Application Development"

---

## **Skills & Concepts Demonstrated:**

* (AI) Agents

* Embeddings
